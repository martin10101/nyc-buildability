# Helper briefing and helper answers — required project workflow

Owner directive D-094 R307-R315 (2026-10-15). Always loaded: no `paths:` frontmatter, so every session and every helper
follows it without being told again.

- **Main session:** before any helper (subagent) is sent a question or task, run `/dispatch-brief` (or apply its five
  parts): the exact answer needed and the decision it serves; the exact scope (branch, pinned commit, files, records,
  reference cases); the evidence that could change the answer; what is unknown and stays unknown; the depth and when to
  stop. Append its return contract. The brief goes to the helper, never to the owner.
- **Every helper:** go to the original source; tie each finding to its evidence and to what it changes; keep verified
  facts, reported claims, inferences, assumptions and unknowns apart; say what was not checked; start the reply with the
  answer, then the support; all parts in one hand-back.
