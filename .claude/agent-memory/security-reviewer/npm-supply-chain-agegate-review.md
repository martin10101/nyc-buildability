Reviewed PASS at PR #64 head 3bbb594. Method for any future npm dep/audit change:

**Blocking audit is genuinely fail-closed (the key gate):** two layers after `npm ci --no-audit` — `npm audit --audit-level=low` (non-zero exit on any advisory >= low) AND a node one-liner reading `require($RUNNER_TEMP/npm-audit.json).metadata.vulnerabilities.total` with `if(t!==0)process.exit(1)`. `metadata.vulnerabilities.total` is the correct aggregate in npm auditReportVersion 2 (sums info+low+moderate+high+critical), so it catches `info` findings the level flag alone passes. Fail-closed even on schema drift: if `metadata.vulnerabilities` is undefined, `.total` throws -> non-zero exit; if `total` is undefined, `undefined!==0` -> exit 1. Confirm identical gate in BOTH ci.yml web job and scheduled-npm-audit.yml. Runtime proof: `gh run view <web-job-run> --log | grep "total vulnerabilities"` -> `found 0 vulnerabilities` + `npm audit total vulnerabilities=0`.

**Age-gate is the .npmrc, not a script (unlike Python):** `min-release-age=7` governs resolution only when the lock is regenerated/installed under npm >= 11.10.0 — hence the 11.18.0 pin + `test "$(npm --version)"=="11.18.0"` version-check in every lock-touching job (web, web-e2e, generate-lockfile, scheduled-npm-audit). Grep the changed files for `min-release-age-exclude` — must be ZERO (an exclude carves a hole in the age rule and the policy bans it). The only `allowlist|--ignore|ignore-vuln` hits should be comments asserting NONE are used.

**Lockfile provenance/integrity (do this in Python, lockfileVersion 3):** load `packages{}` from head+main lock via `git show <ref>:apps/web/package-lock.json`. (a) NEWLY-ADDED package NAMES (head-main) must be NONE for a pure-bump task (zero new maintainer/lifecycle/typosquat surface); (b) every `resolved` starts `https://registry.npmjs.org/` (no mirror/typosquat host); (c) every resolved entry has `sha512-` integrity; (d) STRONGEST anti-forgery: for each changed direct/override pkg, fetch `https://registry.npmjs.org/<pkg>` and assert committed `integrity` == `versions[ver].dist.integrity` (M0-T019: all 5 matched live registry). M0-T019 delta was 15 changed / 0 added / 3 removed (`@swc/counter`,`busboy`,`streamsearch` dropped by next 15.5.20 = surface reduction); old postcss 8.4.31 (ReDoS GHSA-7fh5-64p2-3v2j) -> 8.5.10 via override.
