What does “law text matched” mean?

When this rule was built, the exact sentence of the Zoning Resolution it relies on was captured and sealed with a digital fingerprint. Every time the system starts, it re-checks the seal. If the law text changed — an amendment, a correction, anything — the rule refuses to run until a human re-reviews it. No answer is safer than an answer computed on law that shifted.
