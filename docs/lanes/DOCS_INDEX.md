- **What each lane start runs.** `python -m tools.agent_supervisor.mrl_launch_draft …`, then `python -m tools.agent_supervisor start … --max-cycles 1` (`commission_lanes.ps1:758-790`; `docs/MRL_LAUNCH_RUNBOOK.md:23-35`). Other limits: lanes start 60 s apart (`:107`); packet ids must match `^M\d+-T\d+$` (`:691`); the base ref is pinned to `refs/heads/main` (`:769`).
- **Consequence.** Step 10 of Prompt 0 (an agent-run `launch_lanes.sh`, `docs/lanes/LOOP_LAUNCH_PROMPTS.md:165-170`) is not permitted as written (conflict row 4).
