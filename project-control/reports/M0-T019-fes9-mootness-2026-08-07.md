## 7. Why this is a STRICTLY STRONGER security outcome

The authorized action (am.1) was a **deliberate, reviewed weakening**: adding a real code-level
exception path to a fail-closed security control, admitting one pin under age for a bounded window.
The realized outcome is the **absence** of that weakening:

1. The global 7-day threshold is untouched (R010).
2. No package — not even the two named pins — is admitted under age; both clear the gate on real
   registry age (§3).
3. The gate ships byte-identical to the version G3/G5 already reviewed (§5); no new attack surface,
   no allowlist parser, no expiry-clock logic to get wrong.
4. The gate-header and policy-doc "no exception path" assertions stay TRUE and untouched. (The
   task-file acceptance scenarios FE-S5/FE-S8/FE-S9/FE-S12 had been pre-edited at am.1 to anticipate
   a machine-realized exception and were reconciled to the mootness outcome by the orchestrator after
   G3 caught the contradiction — see the R021 row in §6.)

A control that was authorized to be weakened but ships **unweakened** while still admitting the
needed pins is strictly stronger than one that ships with the weakening. The owner's stated concern
— age as npm-incident "infection protection" — is fully met: both named pins are advisory-free,
published before the 2026-08-04 incident window, and now satisfy the full 7-day protection with no
exception.

This is reinforced by TWO consecutive transitive-advisory rounds, both resolved under the UNCHANGED
gate with advisory-free AND ≥7-day versions and **zero age exceptions**:

1. **Round 1** (`brace-expansion` under the eslint/minimatch/glob tooling) — remediated to
   `1.1.18`, which cleared 7 days on real age before this record.
2. **Round 2** (`js-yaml@4.3.0` single dev-tree instance) — a NEW HIGH advisory
   (CVE-2026-59870 / GHSA-5p4m-2wfm-xmqj) disclosed after 2026-08-05 was caught by the blocking
   `npm audit` in lockfile run 31211100620 (the fail-closed gate working exactly as designed), then
   remediated to `js-yaml@4.3.1` (advisory-free, ~7.07 days old — cleared the plain 7-day gate ~1.7 h
   before capture). Run 31211311419 then passed all validations.

In both rounds the gate held its full 7-day threshold and no exception path was ever created — the
demonstrated behavior is stronger than the authorized weakening, not weaker.
