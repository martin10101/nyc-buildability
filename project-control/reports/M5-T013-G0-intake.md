- **8 executable AS:** (1) evidence document assembled over server-rebuilt facts, byte-equal to its sources; (2) transport-never-interpret — no legal interpretation, no recomputation, cap and citations byte-identical; (3) body-less, zero untrusted-input surface; (4) flag-gated generic-404 fail-safe reusing the existing flag, config.py untouched, no OpenAPI leak; (5) documented `STATUS_STATE_MATRIX`, honest 200 non-errors with typed reasons, `X-Correlation-ID`, no leaky error bodies; (6) fail-closed serialisation with every stage guarded and both `json.dumps` forms proven; (7) never Verified unless the source says so, with the invariant scoped to server-authored content; (8) additive registration + offline (egress landmine) + full regression + modularity.
- **Rationale (D-038-R003):** this is the **Evidence view** named in the original pivot plan (Compare UI → Evidence view → rule families) and never built. The provenance data already exists — `_closed_provenance` records in `profile/builder.py`, per-citation provenance via `rules/evaluator.py::_citations_with_provenance`, `rules/integration.py::_input_provenance`, snapshot provenance — and **no API surface exposes any of it**, so a user sees conclusions with no way to audit them. The product's credibility rests on a claim it currently cannot show.
- **Two design decisions worth reviewing, both learned from M5-T012:**
  1. **Deliberately body-less.** M5-T012 had to accept a request body, and the gate wave found two BLOCKING defects in precisely that boundary (an unpaired surrogate crashing all four endpoints; fact keys enforced top-level only). This endpoint needs no caller input, so the packet forbids inventing one — the untrusted-input surface is zero, not merely guarded.
  2. **M5-T012's gate findings are acceptance criteria up front, not things to be told twice.** AS-6 requires every stage exception-guarded (M5-T012's G1/G5 HIGH-1 was an unguarded final stage) and requires the response to survive *both* `json.dumps(doc, allow_nan=False)` and `json.dumps(doc, ensure_ascii=False, allow_nan=False).encode("utf-8")`, because those two disagree about unpaired surrogates and the renderer uses the second — which was G5's BLOCKING-1 exactly. AS-7 states the never-Verified invariant with its scope (server-authored content) and its documented limit, per the three reviewers who showed a blanket token scan is falsifiable.
- **Transport-never-interpret is the correctness boundary reviewers must probe hardest.** The temptation in an evidence view is to tidy, summarise, or "helpfully" restate a citation. Any such rewriting changes legal meaning. Every material value must be byte-equal to its source, and a thin or conflicting trail must surface as a typed 200 reason — the user seeing that the evidence is thin *is* the answer.
