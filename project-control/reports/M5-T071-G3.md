## Part 2 of 3: contract fidelity per review question

**(1) DB-047(d) copy gating — complete and correct against the real leaf, not just the mock.** I verified the observed signal at source rather than trusting the mock. `aria-label="Interactive approximate lot outline map"` occurs exactly once in production code, at `LotOutlineMap.tsx:646`, inside the branch `view.outcome === "single_lot" && !view.geometryUnusable && drawable && !mapRenderFailed`. The observer transition test is sound and not a tautology. Its premise is that the effect keys on `[bbl]`, so a same-`bbl` rerender cannot re-run it — only the `MutationObserver` can re-sync the copy. I confirmed that premise against `ProposalOutlineMap.tsx:117-131`. The re-entrancy concern is handled: the observer fires on the instruction paragraph's own text change, but `setMapRendered((prev) => (prev === present ? prev : present))` makes that a React bail-out, so there is no update loop.

**(2) DB-047(e) finiteness gate — correct, and no NaN row can reach the payload.** `Number.isFinite` is applied to both ordinates (`ProposalOutlineDraw.tsx:153-155`), which also rejects ±Infinity; the unit test pins the Infinity case. Finite-flow byte-compatibility (AS-3) holds under inspection. `convert()`'s filter is a no-op on an all-finite array, so the payload is unchanged. The status announces `finitePointCount(points)`, which equals `points.length` when all points are finite. The disabled-hint's `incompleteCount === 0` branch renders the same characters as the prior JSX: the old text node `" to\n          convert — an outline needs at least "` collapses to `" to convert — an outline needs at least "` under JSX whitespace rules, matching the new template literal exactly. No prop signature on either component changed.

Note that dropping the guard is a single mutation that duplicates both the source and its two layers, so the sourceAddCounts tooth covers the layer case too — no tooth was traded away.
