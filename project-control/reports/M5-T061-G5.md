## Threat-surface walkthrough (proposal_checks_api.py / _proposal_fact_domains.py)

Request pipeline order (`post_proposal_checks`, lines 455-622): flag gate 404 → correlation id → declared-length 413 → bounded-stream 413 → empty/parse/dict 422 → whole-body strict-JSON guard (`allow_nan=False`) 422 → boundary shape refusals → `_require_label` on scenario_label/proposal_id → `_enforce_route_caps` (BP-4) → `_validate_exterior_wall_ids` (DB-039(h)) → fact-key bound → fact-type check → resolve registry (event loop) → `_validate_lot_rule_fact_domains` (DB-039(d)/(e)) → threadpool `validate_proposed_massing_input` (the O(n²) gate) + `_build_lot_context` → threadpool `check_proposal`.

1. **Caps before expensive compute / O(n²) gate unreachable with oversized input.** `_enforce_route_caps` (lines 418-452) runs before the gate and refuses when `_total_position_count` (verified O(#outlines), each O(1) len, proposal_input_gate.py:102-113) exceeds `ROUTE_MAX_TOTAL_OUTLINE_POSITIONS=1200`, strictly below the inherited `MAX_TOTAL_VERTICES=5000` (import-time guard, lines 179-183). The T057 ~17s stall (2.5e7 pair tests at 5000 verts) is closed: the gate is reached only with ≤1200 positions (~1.44e6 pair tests) and runs off the event loop via `run_in_threadpool` (lines 571, 589). Test `test_bp4_outline_position_over_cap_refused` binds the pre-gate refusal; `test_cpu_bound_calls_run_off_the_event_loop` binds both offloads.

2. **Numeric domain validation — no bypass (independently probed).** Registry-derived bounds only (`derive_input_domains`, _proposal_fact_domains.py:259-330; every kept bound copied from an `InputSpec` field verified to exist in rules/models.py:29-32; per-direction every-declaring-rule conservatism, most-permissive kept). Probe results: NaN → 422 generic body-guard message, keys exactly `{state,message,correlation_id}`, value not echoed; Infinity → 422 same; `1e400` (→inf) → 422 body guard; `1e4` over-max → 422 `field=lot_rule_facts.lot_depth_ft`, no echo; 60-digit int over-max → 422 (no overflow, big-int vs float compare correct); `-5` and `-0.0` below-min → 422; bool `true` → 422 (bool excluded via `isinstance(value, bool)` in both type check line 124 and domain check line 373). Unicode digit forms cannot reach the numeric path: JSON numbers are ASCII-only, so unicode digits arrive either as a string (type refusal, must-be-a-number 422) or an unparseable token (malformed-JSON 422). All refusals name the field and echo the accepted range only, never the value (`_NumericBounds.refusal_reason`/`describe`, lines 166-189).

3. **Reflection / echo boundedness.** Field on every response and log path is capped by `_bounded_field` (MAX_FIELD_LEN=200, lines 244-250). Message via imported `_bounded_message`. Labels/ids via `_require_label` with charset `[A-Za-z0-9 ._:\-]` `fullmatch` (rejects markup, quotes, path separators, trailing newline) and refusals that echo length only (_proposal_fact_domains.py:63-79). Tests: `test_bounded_field_helper_caps_hard`, `test_wall_id_bad_charset_refused`, `test_wall_id_over_length_refused_length_only`, `test_lot_line_id_over_cap_refused_and_bounded`, `test_street_wall_id_bad_charset_refused`, `test_area_provenance_over_ceiling_refused`, `test_lot_rule_facts_key_bound_and_unmapped_stays_bounded`.
