Containment (honest): fail-closed — generic message, correlation-id-only ERROR log, no partial scene, no stack trace to client, rate-limited. So NO data leak. The defect is that a purely caller-controlled input reaches the untyped-exception path (generic 500) instead of the typed 422 the contract promises.
