M5-T101 G5 — PART 2/3: log injection (AS-3) + refusal hygiene.

Single chokepoint verified: _safe_correlation_id at entry (bf 1023); the raw correlation_id param is used nowhere after it; the connector's ONLY log site (bf 1061 logger.error) logs the sanitized cid; the transport is fed self.cid sanitized (bf 606). Class-name trailing-newline stripped before the allowlist `$` gap; secret-in-exception-message omitted (fixed message + class only, never str(exc)); typed refusal emits no ERROR record. All confirmed by passing probes + suite.

- FINDING L-1 (LOW/ADVISORY; bf 435 _CONTROL_CHAR_DELETE, 448-455 _safe_correlation_id): the correlation-id sanitiser strips CR/LF/NUL/all C0/C1/DEL/NEL/ESC (verified) but NOT U+2028 / U+2029. Probe: _safe_correlation_id("A"+U2028+"B") returns it unchanged, and str.splitlines() splits the result into 2 lines — so a caller cid carrying U+2028/2029 reaches BOTH log sites with the separator intact. The packet spec said "control characters" (U+2028/9 are separators, not Cc), and the class-name/message fields are already safe (the allowlist repr-escapes them), so this is defense-in-depth — but the threat model named U+2028/2029 explicitly. Remediation: add 0x2028, 0x2029 to _CONTROL_CHAR_DELETE (one line) + a probe.

- FINDING L-2 (LOW/ADVISORY; bf 448-455): the cid is NOT length-bounded at the log sites (class-name/message ARE, via _sanitized_bounded → 200). Probe: _safe_correlation_id("z"*5000) → len 5000. A caller can log an arbitrarily long printable cid at every site, incl. once per retry ATTEMPT in the shared transport (log-volume amplification). Remediation: bound the sanitized cid (reuse _LOG_FIELD_MAX).

- BACKLOG (pre-authorised by the threat model): the shared transport (app/resilience/transport.py 460-495) logs correlation_id RAW at 5 sites (timeout/network/429/server-error), no re-sanitize/bound. For THIS connector the value arrives pre-sanitized, so no C0/C1/CR/LF reaches it — but other connectors may pass a raw cid, and L-1/L-2 flow through. Out of scope (forbidden path). Recommend backlog: sanitize+bound the cid centrally in the transport (or require every connector to pass a sanitized cid).
