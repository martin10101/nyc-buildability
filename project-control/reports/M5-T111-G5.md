FINDING 1 — MEDIUM, ADVISORY (must-fix before PKT-H enables) — job-slot leak in the pre-thread-start cancellation window. rate_limit.py:240-251 run_in_job_slot: try_acquire() increments the slot, then `await asyncio.wait_for(runner(_guarded), timeout)`. slots.release() lives ONLY in _guarded's finally, which executes only once the worker thread runs work(). If wait_for's deadline cancels the await WHILE run_in_threadpool is still waiting for an anyio thread-pool token (pool saturated), _guarded never runs, its finally never runs, and the slot is leaked permanently (no reaper; reset() is test-only). Reachability: Sigma(max_slots)=3x16=48 exceeds the anyio 40-thread pool (producer OBSERVED), so token starvation is reachable once the routes are mounted under concurrent load with the 10-15 s per-request deadlines firing during token-wait. NOT reachable while UNMOUNTED (this packet's shipping state), and it fails CLOSED (availability only — no bypass, no data exposure).
