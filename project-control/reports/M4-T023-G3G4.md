- **F2 (note) — `r5b-height`, `r5d-height`, `example.expected.basis`.** The basis is a paraphrase ("R5B maximum building height 35 feet") rather than the capture's generic sentence ("In the district indicated, the maximum building height shall be 35 feet"); the R5/R5B/R5D statement-to-district association in zr-23-422 is itself a `needs_review` item in that capture. Low impact; optional to add a gap line.
- **F3 (note) — test file, `test_editing_a_rendered_file_is_caught_by_the_checker`.** This test does not actually run the checker/`rendered_errors` against tampered on-disk content; it only builds a tampered string in memory and asserts the on-disk file still matches the renderer. The real byte-identical guard is covered by the other three S8 tests and the producer's on-disk S8 mutation proof, so coverage is not missing — the test name is just misleading. Rename or strengthen it to call `rendered_errors` on a tampered copy.

For R2X the qualifying value (1.00) equals the standard value (1.00), so "higher" is inaccurate for R2X. Reword to "(R4 1.50; R2X unchanged at 1.00)".
