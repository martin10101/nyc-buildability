## Findings

**F-1 (Advisory, test thoroughness — pre-existing).** No dedicated regression test pins the non-`NEXT_PUBLIC_` server-side-only posture that S2 calls out. A coordinated two-point mutation (const value + test `KEY` both switched to a `NEXT_PUBLIC_…` name) would pass all tests while inlining the flag into the client bundle. The posture is currently verified only by source inspection + a one-time producer grep (which I reproduced: no `NEXT_PUBLIC_…RULE_EVAL` anywhere). This gap pre-dates M5-T019 (inherited from M4-T005) and is not worsened by the rename. Not blocking. Optional future hardening: a unit assertion `expect(INTERNAL_RULE_EVAL_ENABLED_ENV_VAR.startsWith("NEXT_PUBLIC_")).toBe(false)`.

**F-2 (Advisory, coverage — pre-existing structural).** No e2e proves env-absent → surface-disabled end-to-end, because the single-server Playwright harness sets the flag once for the whole `next start` process. The invariant is covered deterministically at the unit level (`OFF by default`, `absent → false`, and the new inert-guard). Not blocking; a structural property of the harness, not a defect in this task.
