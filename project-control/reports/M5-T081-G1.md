Part 2/3: M5-T081 — ruling on $INSUNITS 21 inside an AC1009 file (question A), advisories, verdict.

RULING — writing code 21 into an AC1009 (R12) file is ACCEPTABLE and correct. $INSUNITS is a NAME-addressed HEADER hint (9/$INSUNITS, value on 70) that governs only DesignCenter/block-insertion auto-scaling; it never affects whether the file opens or how the literal double coordinates are read. Reader classes:
- Genuine R12-era reader (pre-R2000, before $INSUNITS existed): skips the unknown 9/$INSUNITS variable BY NAME — no effect.
- R2000-2016 reader (knows $INSUNITS, value table stops at 20): reads 21 as out-of-range -> unitless / no auto-scale. Benign: file still opens; only block-insertion scaling is unset, and only if the drawing is inserted elsewhere. No geometry mis-scale, no load failure.
- 2017+ reader incl. ALL current AutoCAD (the stated "opens natively" target): reads 21 = US Survey Feet — the survey-accurate truth for EPSG:2263.
The anachronism (2017-era value in an R12 tag) is inherent to $INSUNITS itself (postdates R12) and is universally tolerated — NOT a reason to bump the version. The exact CRS is ALSO on the ANNOTATION layer, so no unit fact depends solely on $INSUNITS. Conclusion: no version or note change needed; the corrected comment is accurate; my prior F1 is RESOLVED. Runtime-confirmed: writer emits `$INSUNITS / 70 / 21`; reader reports units.code=21, name=us_survey_feet.

Residual advisories (both ADVISORY, non-blocking):
- A1: pre-2017 readers report the drawing unitless-for-insertion (don't recognize 21) — benign, and strictly BETTER than code 2 (universally understood but the WRONG unit for survey-foot data).
- A2: TABLES emits only LTYPE+LAYER (no STYLE/VPORT); TEXT uses the default STANDARD style that no STYLE table defines. Modern AutoCAD reconstructs STANDARD/VPORT and opens the file; a strict/old importer might warn. I could not run AutoCAD itself; openability rests on documented modern-AutoCAD tolerance + clean round-trip.

New bounds reviewed, FORMAT-NEUTRAL: MAX_COORD_ABS=1e8 at _format_real refuses only |coord|>1e8; NYC EPSG:2263 is ~1e6 (100x headroom) so no real geometry is falsely refused; touches no group code. MAX_FLOORS=2000 + builder pre-checks are input guards. Golden re-anchored; 52 tests green.
